=== 2026-02-16 02:10 - 메뉴 업데이트 "실패" 버그 수정 ===

문제: 메뉴 편집 후 저장 버튼 클릭 시 "메뉴 업데이트에 실패했습니다" 메시지 발생

원인 분석:
1. getDbUpdate() 함수는 PDO의 rowCount()를 반환
   - 성공 시: 변경된 행 수 (0 이상의 정수)
   - 실패 시: false
   
2. 기존 코드 문제:
   ```php
   $result = getDbUpdate(...);
   if ($result) { // ❌ 0일 때 false로 평가됨!
       success
   } else {
       fail
   }
   ```
   
3. 실제 상황:
   - 메뉴 데이터가 변경되지 않은 경우 $result = 0
   - PHP에서 0은 falsy 값이므로 if ($result) 조건이 false
   - 결과적으로 성공했음에도 "실패" 메시지 표시

해결 방법:
- false 체크를 엄격하게 변경: `if ($result === false)`
- 0은 "변경사항 없음"이므로 정상 처리
- 디버그 로그 추가하여 문제 추적 가능하도록 개선

수정 파일:
1. application/libs/admin_header_menu_func.php (line 276-323)
   - $result === false로 에러 체크 변경
   - 디버그 로그 추가 (result 값, 타입 출력)
   - 페이지 콘텐츠 업데이트 결과도 로그에 기록
   - PHP 파일 생성 결과 로그 추가
   
2. application/libs/admin_footer_menu_func.php (line 288-329)
   - 헤더 메뉴와 동일한 방식으로 수정
   - footer_menu 테이블 업데이트 시 동일한 로직 적용

수정 전후 비교:
- 수정 전:
  * if ($result) → 0일 때 실패로 처리
  * if ($result !== false) → 0도 true이지만 위에서 이미 실패 처리
  
- 수정 후:
  * if ($result === false) → false일 때만 에러
  * 0, 1, 2 등 모든 정수는 성공 처리
  * error_log()로 상세 디버깅 정보 출력

테스트 방법:
1. https://mvc.neuralgrid.kr/admin/editMenu/2 접속
2. 메뉴 내용 수정 (또는 수정하지 않고)
3. 저장 버튼 클릭
4. "메뉴가 업데이트되었습니다" 메시지 확인
5. 페이지 타입 메뉴의 경우 콘텐츠도 정상 저장 확인

결과:
